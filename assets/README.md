# Placeholder Assets

This directory contains placeholder assets for the Math Runner game.

## Required Assets

### Character Assets
- `stickman.png` - Basic stickman character (32x48px)

### Gate Assets  
- `gate_add.png` - Green addition gate (80x120px)
- `gate_subtract.png` - Red subtraction gate (80x120px)
- `gate_multiply.png` - Blue multiplication gate (80x120px)
- `gate_divide.png` - Orange division gate (80x120px)

### Obstacle Assets
- `obstacle_barrier.png` - Gray barrier obstacle (40x40px)
- `obstacle_spike.png` - Spike trap obstacle (40x40px)
- `obstacle_enemy.png` - Red enemy obstacle (40x40px)

### UI Assets
- `ui_button.png` - Button background
- `ui_panel.png` - Panel background
- `ui_icons.png` - Various UI icons

### Environment Assets
- `ground.png` - Ground/terrain texture
- `background.png` - Parallax background
- `finish_line.png` - Level finish line

## Note

These placeholder assets will be generated programmatically by the ResourceManager.
For production use, replace these with high-quality artwork from:
- Kenney.nl (recommended free assets)
- Itch.io free assets section
- Custom pixel art created in Aseprite or similar tools

## Asset Specifications

All sprites should use:
- PNG format with transparency
- Power-of-2 dimensions where possible
- Consistent pixel art style
- Clear visual hierarchy for gameplay elements
